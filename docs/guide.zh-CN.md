# ResearchOS 使用指南

ResearchOS 是一个自托管的科研项目工作台：在网页上统一管理多个科研项目、里程碑、任务和实验，
同时让 Claude Code、Codex 等 AI 智能体通过 MCP 查询和更新这些信息。

> 本页是中文快速指南。更详细的参考文档（英文）见左侧：MCP 集成、部署、架构，以及智能体指令模板。

## 1. 核心概念

| 概念 | 说明 |
|---|---|
| **项目** | 一篇论文或一个科研方向。包含研究问题、假设、目标会议/期刊、投稿截止日期、阶段、健康度、优先级、下一步行动和阻塞。 |
| **阶段** | 构思 → 研究设计 → 实现 → 实验 → 分析 → 写作 → 投稿 → 修改 → 已完成（或搁置）。 |
| **健康度** | 正常 / 有风险 / 受阻。总览页的“受阻项目”统计的就是“受阻”。 |
| **里程碑** | 有明确完成标准的检查点。项目进度 = 已完成里程碑 / 未取消里程碑；没有里程碑时显示“未设置”，不会伪造百分比。 |
| **任务** | 具体待办，可关联里程碑，带优先级、截止日期、标签和 Git 引用。 |
| **实验** | 一个对照条件（例如“消融：去掉世界模型”）。用“分组”把同一组消融实验放在一起。 |
| **运行** | 实验的一次实际执行（某个种子/配置），记录提交、配置、指标、产物链接和验证状态。 |
| **动态** | 只追加的科研日志：进展记录 + 所有重要变更，标注来源（手动、Claude Code、Codex、REST API、系统）。 |

## 2. 日常使用

### 总览（每天打开的页面）

- 顶部 5 张卡片：进行中项目、未完成任务、运行中实验、即将到期（14 天）、受阻项目。点击可跳转。
- 中间：所有项目的卡片或表格，可按阶段/优先级/健康度筛选并排序。
- 底部：即将到期、最近科研动态、待审核实验。

### 新建与编辑

- 右上角 **新建** 菜单：项目、任务、实验、进展记录。
- 项目详情页顶部的三个下拉框可以直接修改 **阶段 / 健康度 / 优先级**。
- 项目详情页有 6 个标签：总览、里程碑（带时间线）、任务（看板/列表）、实验、动态、笔记（Markdown + 外部文档链接）。
- 看板：电脑上直接拖动卡片；手机上按住卡片左侧的 ⋮⋮ 拖动，或用卡片底部的状态下拉框。

### 跨项目视图

- **任务**：预设“未完成 / 最高优先级 / 7 天内到期 / 已逾期 / 受阻 / 全部”，可再按状态、优先级、日期、关键字筛选；逾期任务会高亮。
- **时间线**：按项目的近期时间线，或切换到 **日历** 查看整月的投稿、里程碑和任务截止日期（点击日期查看当日事项）。
- **动态**：按项目、来源、事件类型、时间筛选全部活动。
- 顶部 **全局搜索**（⌘K / Ctrl+K）可搜索项目、任务和实验。

## 3. 记录实验的建议

1. 每个对照条件建一个实验，例如“完整模型（基线）”“消融：去掉世界模型”，放进同一个 **分组**。
2. 每个种子/配置添加一次 **运行**，填写运行 ID（如 W&B ID 或 `<commit>-seed0`）、种子、提交、指标和单位。
   再次使用同一个运行 ID 会更新该运行，不会重复。
3. 实验列表和详情页会显示各指标跨运行的 **均值 ± 标准差**。
4. 检查过证据后，点击 **标记为已验证**。智能体只能把结果记为“待审核”，不能自行标记为已验证；
   修改已验证的结果需要你明确确认。
5. 大文件（模型权重、视频、原始日志）不要上传，只填路径或链接。

## 4. 接入 Claude Code / Codex

1. **设置 → 新建令牌**：选择“读写”，名称建议包含 `claude` 或 `codex`（动态来源会自动标注）。令牌只显示一次。
2. 在运行智能体的机器上设置环境变量：`export RESEARCHOS_TOKEN=ros_...`
3. 注册 MCP 服务器（地址用你实际访问 ResearchOS 的地址，例如 Tailscale 地址）：

```bash
# Claude Code
claude mcp add --transport http researchos https://<你的地址>/mcp \
  --header "Authorization: Bearer $RESEARCHOS_TOKEN"

# Codex
codex mcp add researchos --url https://<你的地址>/mcp --bearer-token-env-var RESEARCHOS_TOKEN
```

4. 把 [CLAUDE.md 模板](../templates/CLAUDE.md) 或 [AGENTS.md 模板](../templates/AGENTS.md) 复制到科研仓库根目录，并填写项目短标识。
5. 然后就可以对智能体说：“记录今天的进展：完成了 WBC 基座补偿模块，下一步做仿真消融”
   或“列出未来 7 天所有项目未完成的任务”。

完整说明与工具列表见 [MCP 集成](mcp-integration.md)。

## 5. 远程访问（Tailscale）

ResearchOS 默认只监听服务器本机。推荐用 Tailscale 在私有网络内通过 HTTPS 访问：

```bash
docker compose --profile tailscale up -d
docker compose logs tailscale        # 首次需要打开日志里的登录链接授权
```

授权后即可在你 tailnet 内的设备上访问 `https://researchos.<你的tailnet>.ts.net`。
首次使用需在 Tailscale 管理后台开启 **MagicDNS** 和 **HTTPS Certificates**。
详细步骤见 [部署文档](deployment.md#option-a--tailscale-serve-docker-sidecar)。

## 6. 备份与升级

```bash
scripts/backup.sh                              # 在线安全备份到 ./backups/
scripts/restore.sh backups/researchos-<时间>.db  # 恢复（会先保存当前数据库）
git pull && docker compose up -d --build       # 升级，数据库迁移自动执行
```

也可以在 **设置 → 数据 → 导出 JSON** 导出全部数据。

## 7. 常见问题

| 问题 | 解决办法 |
|---|---|
| 智能体写入后网页没变化 | 网页每 30 秒及切回窗口时自动刷新；也可以手动刷新。在“动态”里按来源筛选确认。 |
| 智能体报 `insufficient_scope` | 令牌是只读的，请新建“读写”令牌。 |
| 智能体报 `confirmation_required` / `verified_protected` | 这是保护机制：完成/归档项目、修改已验证结果需要你明确同意后再让智能体带确认参数重试。 |
| 忘记管理员密码 | 服务器上运行 `docker compose exec researchos python -m app.cli set-password`。 |
| 切换语言 | 顶部栏的语言按钮，或 设置 → 外观。 |
