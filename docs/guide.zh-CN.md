# ResearchOS 使用指南

管理科研项目、任务和实验；通过 MCP 接入 Claude Code 或 Codex。

## 1. 建立项目

点击 **新建 → 项目**，填写研究问题、目标会议、投稿日期和下一步行动。

- **阶段**：构思、研究设计、实现、实验、分析、写作、投稿、修改、已完成或搁置。
- **健康度**：正常、有风险、受阻。
- **里程碑**：有明确完成标准的检查点。项目进度按已完成里程碑占比计算，取消的里程碑不计入。
- **任务**：具体待办，可设置优先级、截止日期和标签。项目可选“无项目”，之后可再归入项目；关联项目后可选择里程碑。

在项目详情页修改状态、管理任务、记录进展和编辑笔记。

## 2. 日常查看

| 页面 | 用途 |
|---|---|
| 总览 | 查看项目状态、近期截止日期和待审核实验 |
| 任务 | 跨项目筛选待办、逾期和受阻事项；在看板中拖动卡片更新状态 |
| 项目排序与图标 | 拖动项目卡片调整顺序（触屏拖右上角手柄，键盘聚焦手柄后用方向键），总览、侧边栏和 Agent 读取的都是这个顺序。点击项目图标可从内置的科研图标库中选择图标和颜色 |
| 看板 | 卡片可跨列拖动改状态，也可在列内拖动调整顺序（键盘：手柄 + ↑/↓） |
| 甘特图 | 时间线页默认视图，每个项目页也有“甘特图”标签页：按项目分组的任务条形图，含里程碑、投稿截止、今日线和“完成后开始”依赖箭头（红色表示开始早于前置任务结束）。拖动条形改排期、拖两端改时长；键盘 ←/→ 移动，Shift+←/→ 改结束日期。开始日期和前置任务在任务表单中设置 |
| 时间线 / 日历 | 查看投稿、里程碑和任务截止日期 |
| 动态 | 按项目、来源和时间查看进展与变更 |

按 **⌘K / Ctrl+K** 搜索项目、任务和实验。手机看板可用卡片上的状态菜单。

## 3. 记录实验

1. 每个对照条件建一个**实验**，同一组消融使用相同分组名。
2. 每个种子或配置添加一次**运行**，记录运行 ID、Git 提交、参数、指标和产物链接。同一实验内重复使用运行 ID 会更新原记录。
3. 页面按指标汇总各次运行的**均值 ± 标准差**。
4. 核对结果后手动标记**已验证**。智能体不能自行验证；修改已验证结果需要确认。
5. 实验的**描述**、**结论**和项目**笔记**支持 Markdown 和图片（曲线图、截图）：点**插入图片**、直接粘贴或拖入 PNG/JPEG/GIF/WebP（≤ 10 MB）。图片存在数据卷的 `uploads/` 下，`scripts/backup.sh` 会同步到 `backups/uploads/`。

模型权重、视频和原始日志只记录路径或链接。

## 4. 接入智能体

在 **设置 → 新建令牌** 中选择读写权限，复制令牌并在智能体运行环境中设置：

```bash
export RESEARCHOS_TOKEN='ros_...'
```

按 [MCP 集成](mcp-integration.md) 注册服务，再将 [CLAUDE.md](../templates/CLAUDE.md) 或 [AGENTS.md](../templates/AGENTS.md) 模板放入科研仓库，填写项目短标识。

示例：“记录今天的进展：完成基线复现，下一步做消融。”

## 5. 备份与维护

```bash
scripts/backup.sh                              # 备份到 ./backups/
scripts/restore.sh backups/researchos-<时间>.db  # 恢复，先保留当前数据库副本
scripts/update.sh                              # 备份、构建并检查服务状态
```

**设置 → 数据 → 导出 JSON** 可导出科研数据。远程访问和服务器配置见 [部署](deployment.md)。

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 智能体写入后页面未更新 | 页面每 30 秒及切回窗口时刷新；也可手动刷新，在“动态”中核对记录 |
| `insufficient_scope` | 换用读写令牌 |
| `confirmation_required` / `verified_protected` | 确认操作后，让智能体带确认参数重试 |
| 忘记密码 | 运行 `docker compose exec researchos python -m app.cli set-password` |
| 切换语言 | 顶部语言按钮或 **设置 → 外观** |
